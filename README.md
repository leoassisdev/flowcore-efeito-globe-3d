## Como instalar

1. **Instale as dependências**

   ```bash
   npm install three @react-three/fiber @react-three/drei
   ```

2. **Crie src/components/Globe3D.tsx** Copie o conteúdo de `src/Globe3D.tsx` deste repositório.
3. **Stub — código completo na Aceternity**
